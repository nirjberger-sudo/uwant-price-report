# דוח ניטור מחירי UWANT — אתר ההשוואה

**האתר החי:** https://nirjberger-sudo.github.io/uwant-price-report/
(repo: https://github.com/nirjberger-sudo/uwant-price-report — ה-repo *הוא* התוכן של `site/`,
כלומר `index.html` יושב בשורש ה-repo, לא בתת-תיקייה).

## עדכון מהיר — כפתור "עדכן דוח" (הדרך המומלצת, בלי טרמינל)

באתר עצמו, למעלה מימין, יש כפתור **"עדכן דוח"**. לחיצה עליו:
1. פותחת בורר קבצים — בוחרים את קובץ ה-`.xlsx` החדש.
2. הדפדפן (לא שרת, לא Claude) מפענח את הקובץ בעצמו ובונה מחדש את `data.json`.
3. בפעם הראשונה בלבד מבקש **טוקן גישה אישי לגיטהאב** (הסבר מלא בתוך הפרומפט שנפתח) —
   הטוקן נשמר רק בדפדפן המקומי (localStorage), לא נשלח לשום מקום מלבד GitHub עצמו.
4. שומר את הקובץ ישירות ל-repo דרך GitHub API. GitHub Pages בונה מחדש תוך כדקה, וכל מי
   שנכנס לקישור רואה את הנתונים המעודכנים.

הלוגיקה שמפענחת את ה-xlsx בדפדפן (`update.js`) היא פורט מדויק של `tools/build_data.py` —
נבדק שהתוצאה זהה ל-100% (אותם מחירים, אותה היסטוריה, אותם extras).

## מבנה התיקייה

```
site/
  index.html          # מבנה הדף
  styles.css          # עיצוב (RTL, מובייל, מצב כהה/בהיר)
  app.js              # לוגיקת הטבלה, חיפוש/מיון/סינון, גרפי היסטוריה
  data/
    data.json         # כל נתוני האתר — הדבר היחיד שמתעדכן בכל דוח חדש
    UWANT_price_report_latest.xlsx   # עותק של הדוח האחרון, להורדה מהאתר
  assets/
    uwant-logo-black.png     # לוגו UWANT (מהאתר הרשמי)
    heebo-hebrew.woff2       # פונט Heebo (Variable, כל המשקלים) — עברית
    heebo-latin.woff2        # פונט Heebo (Variable, כל המשקלים) — לטינית/מספרים
  tools/
    build_data.py      # ממיר קובץ דוח xlsx חדש ל-data.json (ומאחד היסטוריה)
    build_artifact.py  # ארוז את כל האתר לקובץ HTML עצמאי יחיד, כולל שיבוץ הלוגו והפונטים כ-base64 (לפרסום כ-Artifact)
  dist/
    uwant-price-report.artifact.html  # הפלט של build_artifact.py — זה מה שפורסם
```

## עדכון חלופי — מהטרמינל (Python)

זהה בתוצאה לכפתור, שימושי לעדכון גורף/אוטומטי בלי לפתוח דפדפן. **לא נדרש לערוך שום קובץ
קוד.** בכל פעם שיש דוח `UWANT_price_report_*.xlsx` חדש (4 הגיליונות הסטנדרטיים: השוואת
דגמים / קטלוג מלא / סטטיסטיקות / מוצרים נוספים):

```bash
py site/tools/build_data.py "path\to\UWANT_price_report_YYYY-MM-DD.xlsx"
```

הסקריפט:
- קורא את הדוח לפי **שמות הכותרות** בכל גיליון (לא לפי מיקום עמודה), כך שהוא עמיד לשינויים קלים
  במבנה הדוחות הבאים.
- בונה מחדש את מטריצת ההשוואה, הסטטיסטיקות ומוצרי ה"נוספים".
- **מוסיף** נקודת נתון חדשה להיסטוריית המחירים לכל דגם/אתר (לא דורס נתונים ישנים).
- מעתיק את קובץ ה-xlsx עצמו לכפתור ההורדה באתר.

התוצאה: `site/data/data.json` מתעדכן, ו־`index.html` / `app.js` / `styles.css` לא זזים.

אם האתר משרת את הקבצים ישירות (למשל אחרי פריסה ל-GitHub Pages / Netlify / Vercel), זה כל מה
שצריך — פשוט מעלים מחדש את `site/data/data.json` (וקובץ ה-xlsx).

### עדכון גרסת ה-Artifact שפורסמה

אם משתמשים בפרסום כ-Artifact (הדף העצמאי היחיד ב-`dist/`), יש להריץ גם שלב איחוד:

```bash
py site/tools/build_artifact.py
```

זה יוצר מחדש את `dist/uwant-price-report.artifact.html` עם הנתונים המעודכנים משובצים בתוכו
(כולל קובץ ה-xlsx כ-data URI, כדי שגם כפתור ההורדה יעבוד בלי בקשות רשת חיצוניות). את הקובץ
הזה יש לפרסם מחדש.

## מיתוג

הצבעים והפונט לקוחים ישירות מקובץ המיתוג הרשמי של UWANT: כתום `#FF610A`, שחור אלגנטי
`#201F1C`, אפור-בז' `#F5F4F0`, פונט Heebo (כל המשקלים, 100–900). הטוקנים מוגדרים ב-`styles.css`
תחת `:root` — לשינוי צבע יש לערוך שם בלבד.

## דגמים פעילים / מוחרגים

הרשימה מוגדרת בקבוע `ACTIVE_MODELS` בתוך `build_data.py`. הדגמים הבאים מוחרגים במפורש בכל
הרצה: `V500 Plus`, `Y100B`, `Y200B`. לשינוי רשימת הדגמים יש לערוך את הקבוע הזה בלבד.

## חיבור עתידי לדומיין (למשל prices.uwant.co.il)

תיקיית `site/` היא Static Site טהור (HTML/CSS/JS/JSON) ללא תלות בשירות אחסון ספציפי. כדי לחבר
דומיין קבוע:
1. פורסים את תוכן `site/` (לא כולל `tools/`) לשירות כמו GitHub Pages / Cloudflare Pages /
   Netlify / Vercel.
2. מגדירים רשומת CNAME בדומיין `prices.uwant.co.il` שמצביעה לכתובת שהשירות סיפק.
3. כל עדכון עתידי ממשיך להתבצע רק על ידי הרצת `build_data.py` והעלאת `data.json` המעודכן —
   בלי לגעת בקוד.
